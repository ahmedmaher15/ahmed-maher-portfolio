Ahmed Maher Portfolio – Friendly UI v2
=======================================

التعديلات:
- إصلاح موضع وصف About: النص صار في أعلى البطاقة وليس أسفلها.
- تحديث الخبرة إلى 5+ سنوات وفق السيرة الذاتية.
- مقدمة شخصية أبسط وترحيبية.
- فلترة المشاريع حسب النوع مع عرض أول 6 ومشاهدة الباقي.
- قسم مهارات واضح بدل الاعتماد على الشريط المتحرك فقط.
- إظهار اللغات وفق السيرة الذاتية.
- تحسين المسافات والمقاسات على الموبايل.
- الحفاظ على نفس الصور والروابط وبيانات المشاريع.

طريقة التركيب:
1) انسخ app وcomponents وdata إلى جذر المشروع مع استبدال الملفات.
2) لا تحذف public أو package.json أو أي ملفات أخرى.
3) شغّل npm install (عند الحاجة) ثم npm run dev.
4) للتحقق: npm run build.
5) عندما تتأكد من الشكل، git add . ثم git commit -m "Refresh friendly portfolio UX" ثم git push.

ملاحظة: الصور الموجودة في public يجب أن تبقى في نفس المسارات.
